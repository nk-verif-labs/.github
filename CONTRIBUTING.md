# Contributing to NK Verif Labs
Thanks for your interest in improving our templates and verification IP. Bug reports, fixes and new ideas are all welcome.
- **Report a bug:** open an issue with tool versions (Verilator, Icarus, LibreLane, Python), command run, and full error output.
- **Pull requests:** fork from `main`, keep changes focused, verify both simulators pass in CI, and update docs if behavior changes.
- **Code style:** PEP 8 for Python testbenches; consistent indentation and one module per file for Verilog/SystemVerilog.
By contributing, you agree your contributions are licensed under the repository's LICENSE. Questions? Email **nkveriflabs@gmail.com**.
